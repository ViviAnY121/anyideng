## 一、项目背景

随着网络购票普及，用户对"价格变动通知"的需求越来越强烈。本项目以机票订购场景为切入点，在实现基础订票功能之外，重点攻克了一个技术难点：

> **如何在用户不刷新页面的情况下，第一时间感知到航班价格下降？**

最终选择了 **WebSocket（在线实时弹窗）+ Spring Mail（邮件兜底）** 的双通道推送方案。

---

## 二、技术选型

| 层级 | 技术 | 选型理由 |
|------|------|---------|
| 前端 | Vue 3 + Element Plus | Composition API 更灵活，组件库成熟 |
| 后端 | Spring Boot 2.7 | 快速搭建，生态完善 |
| 数据库 | MySQL 8 + JPA | 关系型数据，ORM 减少 SQL 样板代码 |
| 实时推送 | WebSocket（JSR-356） | 浏览器原生支持，双向通信，无需轮询 |
| 邮件通知 | Spring Mail + QQ SMTP | 配置简单，HTML 模板支持良好 |
| 定时任务 | Spring `@Scheduled` | 无需引入额外框架，5分钟扫描一次价格 |
| 异步处理 | Spring `@Async` | 邮件发送不阻塞主线程 |

## 三、系统架构设计

整体采用 **B/S 三层架构 + 前后端分离**：

```
┌─────────────────────────────────────────┐
│            表现层（浏览器）              │
│  Vue 3 · Element Plus · Vuex · Axios    │
│       WebSocket Client (ws://)          │
└──────────────────┬──────────────────────┘
                   │ HTTP / WebSocket
┌──────────────────▼──────────────────────┐
│          业务层（Spring Boot）           │
│  REST Controller · WebSocketServer      │
│  PriceMonitorService(@Scheduled)        │
│  EmailService(@Async)                   │
└──────────────────┬──────────────────────┘
                   │ JPA
┌──────────────────▼──────────────────────┐
│          数据层（MySQL 8）               │
│  users · flights · orders               │
│  flight_schedules · price_watches       │
└─────────────────────────────────────────┘
```

前后端通过两种协议通信：

- **HTTP**：常规 CRUD 接口，`/api/**` 路径
- **WebSocket**：持久连接，`ws://localhost:8080/ws/{token}`，用于服务端主动推送

## 四、数据库设计

核心表共 6 张，降价子系统新增 `price_watches` 表：

```sql
-- 用户价格监控表
CREATE TABLE price_watches (
    id             BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id        BIGINT NOT NULL,
    username       VARCHAR(50),
    user_email     VARCHAR(100),
    schedule_id    BIGINT NOT NULL,          -- 关注的班次
    flight_no      VARCHAR(20),
    route_name     VARCHAR(100),
    seat_type      VARCHAR(20),              -- economy / business
    watch_price    DECIMAL(10,2),            -- 关注时的价格（比对基准）
    target_price   DECIMAL(10,2),            -- 目标价格（可选）
    status         INT DEFAULT 0,            -- 0监控中 2已关闭
    last_alert_time DATETIME,               -- 防重推时间戳
    create_time    DATETIME,
    UNIQUE KEY uk_user_schedule_seat (user_id, schedule_id, seat_type)
);
```

**设计要点：**

- `watch_price` 不是固定值，每次推送后会更新为当前最低价，以便持续追踪更低的价格
- `last_alert_time` 用于防重推，同一条记录 1 小时内最多提醒一次
- 联合唯一索引防止同一用户对同一班次同舱型重复关注

## 五、核心功能实现

### 5.1 Token 鉴权

登录成功后服务端生成 UUID Token，存入内存 Map：

```java
// 登录时颁发
String token = UUID.randomUUID().toString();
TokenUtil.put(token, user);
return Result.success(token);

// 拦截器验证
User user = TokenUtil.getUserByToken(token);
if (user == null) {
    response.setStatus(401);
    return false;
}
request.setAttribute("currentUser", user);
```

WebSocket 连接时在路径中携带 token（`/ws/{token}`），端点内部自行验证，不经过 HTTP 拦截器。

### 5.2 在线购票流程

```
用户搜索 → 选择班次 + 舱型 → 提交订单
    → 后端检查余票 → 扣减 available_economy/business
    → 生成订单（status=0 待支付）
    → 用户支付 → status=1
    → 管理员出票 → status=2 → 触发 WS + 邮件通知
```

## 六、降价提醒子系统详解

这是本项目技术含量最高的部分，整体流程如下：

```
用户点击「🔔 关注降价」
    ↓
POST /api/watches（保存监控记录）
    ↓
Spring @Scheduled 每5分钟扫描
    ↓
检测到：当前价格 < watchPrice
    ↓
用户在线？ ──YES──→ WebSocket.sendToUser() → 前端弹窗
    │
   NO
    ↓
EmailService.sendPriceAlert()（@Async异步）→ 用户邮箱
```

### 6.1 WebSocket 服务端

核心是维护一个 `userId → Session` 的并发安全 Map：

```java
@ServerEndpoint("/ws/{token}")
@Component
public class WebSocketServer {

    // 已登录用户的 session 映射，静态共享
    private static final Map<Long, Session> USER_SESSION_MAP
        = new ConcurrentHashMap<>();

    @OnOpen
    public void onOpen(Session session, @PathParam("token") String token) {
        User user = TokenUtil.getUserByToken(token);
        if (user != null) {
            USER_SESSION_MAP.put(user.getId(), session);
        }
    }

    @OnClose
    public void onClose(Session session) {
        Long userId = (Long) session.getUserProperties().get("userId");
        if (userId != null) USER_SESSION_MAP.remove(userId);
    }

    // 供其他 Bean 调用的静态推送方法
    public static boolean sendToUser(Long userId, String message) {
        Session session = USER_SESSION_MAP.get(userId);
        if (session == null || !session.isOpen()) return false;
        session.getAsyncRemote().sendText(message);  // 异步发送，线程安全
        return true;
    }
}
```

### 6.2 前端 WebSocket 管理器

封装成单例，实现自动重连和心跳：

```javascript
class WebSocketManager {
    connect(token) {
        const url = `ws://${location.host}/ws/${token}`
        this.ws = new WebSocket(url)

        this.ws.onmessage = (e) => {
            const data = JSON.parse(e.data)
            // 收到降价消息，自动弹窗
            if (data.type === 'price_alert') {
                ElNotification({
                    title: `✈ 降价提醒：${data.flightNo}`,
                    message: `${data.routeName} 现价 ¥${data.newPrice}，降了 ¥${data.drop}`,
                    type: 'success',
                    duration: 0  // 不自动关闭
                })
            }
        }

        this.ws.onclose = () => this._scheduleReconnect()
    }

    // 指数退避重连：1s, 2s, 4s, 8s, 16s
    _scheduleReconnect() {
        const delay = Math.pow(2, this.reconnectCount++) * 1000
        setTimeout(() => this._createConnection(), delay)
    }
}

export default new WebSocketManager()
```

登录成功后在 `Layout.vue` 的 `mounted` 钩子里调用 `wsManager.connect(token)`，全局生效。

### 6.3 定时价格监控

```java
@Service
public class PriceMonitorService {

    @Scheduled(fixedDelayString = "${price.monitor.interval-ms:300000}")
    public void scanPriceAlerts() {
        List<PriceWatch> watches = watchRepo.findByStatus(0); // 查监控中的记录

        for (PriceWatch watch : watches) {
            // 1小时防重：同一记录1小时内只推1次
            if (watch.getLastAlertTime() != null &&
                watch.getLastAlertTime().isAfter(LocalDateTime.now().minusHours(1))) {
                continue;
            }

            FlightSchedule schedule = scheduleRepo.findById(watch.getScheduleId())
                .orElse(null);
            BigDecimal currentPrice = getPrice(schedule, watch.getSeatType());

            // 检测降价
            if (currentPrice.compareTo(watch.getWatchPrice()) < 0) {
                // WebSocket 推送（用户在线才能收到）
                WebSocketServer.sendToUser(watch.getUserId(), buildMsg(watch, currentPrice));

                // 邮件推送（异步，无论在线与否）
                emailService.sendPriceAlert(watch.getUserEmail(), ...);

                // 更新基准价，下次降价才再提醒
                watch.setWatchPrice(currentPrice);
                watch.setLastAlertTime(LocalDateTime.now());
                watchRepo.save(watch);
            }
        }
    }
}
```

### 6.4 邮件 HTML 模板

邮件内容用纯 Java 字符串拼接 HTML，避免引入模板引擎依赖：

```java
@Async  // 异步发送，不阻塞定时任务线程
public void sendPriceAlert(String toEmail, String username,
                            String flightNo, BigDecimal oldPrice,
                            BigDecimal newPrice) {
    String html = "<div style='background:linear-gradient(135deg,#1a73e8,#0d47a1)'>"
                + "  <h1>航班降价提醒</h1>"
                + "  <p>原价：<del>¥" + oldPrice + "</del></p>"
                + "  <p>现价：<span style='color:#e63946'>¥" + newPrice + "</span></p>"
                + "</div>";

    MimeMessage msg = mailSender.createMimeMessage();
    MimeMessageHelper helper = new MimeMessageHelper(msg, true, "UTF-8");
    helper.setFrom(fromEmail, "飞机订票系统");
    helper.setTo(toEmail);
    helper.setSubject("您关注的 " + flightNo + " 降价了！");
    helper.setText(html, true);  // true = HTML格式
    mailSender.send(msg);
}
```

**QQ 邮箱配置注意事项：**

```yaml
spring:
  mail:
    host: smtp.qq.com
    port: 465
    username: your_qq@qq.com
    password: "授权码"  # 不是登录密码！
    properties:
      mail.smtp.ssl.enable: true
```

`password` 填写的是 QQ 邮箱"授权码"，需要在 QQ 邮箱 → 设置 → 账户 → SMTP服务 里开启并生成。

## 七、维护记录

### 注1：Lombok 在某些 Mac 环境下注解处理器不生效

**现象：** `mvn compile` 报大量 `找不到符号` 错误，所有 getter/setter 和 `log` 变量均提示未定义。

**原因：** Lombok 依赖注解处理器（APT）在编译期生成代码，部分 Maven 版本 + JDK 组合下 APT 不会自动启用。

**解决方案：** 彻底移除 Lombok，改为手写 getter/setter，`@Slf4j` 改为：

```java
private static final Logger log = LoggerFactory.getLogger(ClassName.class);
```

虽然代码量增加，但完全不依赖环境配置，任何 JDK 版本都能编译通过。

### 注2：`@ServerEndpoint` 的 Bean 注入问题

**现象：** WebSocket 端点类里 `@Autowired` 注入的 Bean 全为 `null`。

**原因：** `@ServerEndpoint` 注册的类不由 Spring 容器管理生命周期，每次新连接都会 `new` 一个实例，导致依赖注入失效。

**解决方案：** 将需要的 Service 存为 `static` 字段，通过 `@PostConstruct` 或构造器注入：

```java
private static EmailService emailService;

@Autowired
public void setEmailService(EmailService emailService) {
    WebSocketServer.emailService = emailService;
}
```

或者更简单地——把推送逻辑设计成 `static` 方法，只操作 `ConcurrentHashMap`，不依赖 Spring Bean。

### 注3：WebSocket 心跳与 Nginx 超时

**现象：** 生产环境下 WebSocket 连接约 60 秒后自动断开。

**原因：** Nginx 默认代理超时为 60 秒，空闲连接会被强制关闭。

**解决方案：** 两边都要配置：

前端每 30 秒发送一次 ping：
```javascript
setInterval(() => ws.send(JSON.stringify({type: 'ping'})), 30000)
```

Nginx 配置：
```nginx
location /ws/ {
    proxy_pass http://backend;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_read_timeout 3600s;  # 延长超时
}
```
